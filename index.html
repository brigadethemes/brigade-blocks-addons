    Brigade Blocks Addons documentation

    Everything you need to build beautiful pages with Brigade Blocks Addons — from installing the plugin to styling every part of every block.

    What is Brigade Blocks Addons?

    Brigade Blocks Addons adds 50 professionally designed blocks to the WordPress Block Editor (also called Gutenberg) — no page builder needed. You use them exactly like WordPress’s own blocks: click +, pick a block, type your content and adjust the settings in the sidebar.

    The blocks are organised into 9 modules that you can switch on or off, so your site only loads what you actually use. Every block can be styled in depth from the editor’s Styles tab — colours, typography, spacing, borders, shadows, layout and more — separately for hover, focus and active states and for desktop, tablet and mobile.

    New here? Follow the Getting Started guide — you will have your first styled section on a page in about ten minutes.

    Highlights

    • Native Block Editor. No page builder, no lock-in. Blocks are rendered on the server, so your content stays safe even if you change your mind later.
    • Deep styling without code. Choose any part of a block (for example a button’s icon or an accordion’s title), a state (Normal, Hover, Focus, Active) and a device (Desktop, Tablet, Mobile), then change its look — see Styling Controls.
    • Fast by default. Styles and scripts load only on pages that use a block; many blocks need no JavaScript at all — see Performance.
    • Accessible. Keyboard support, screen-reader labels and reduced-motion support are built in — see Accessibility.
    • Privacy-friendly. Videos and maps can wait for a click before contacting YouTube, Vimeo or Google; fonts are served from your own site — see External services.
    • The Donix design system. Coral accent, ink headings, the Urbanist typeface and 6px corners — and every colour is a CSS custom property your theme can override.

    How to use this documentation

    Every block guide follows the same structure: Overview, How to add the block, Content settings (every control with its default value, when to use it, an example and the result), Design & styling, Responsive settings, Advanced options, Accessibility, Tips, Limitations and Troubleshooting. Use the search box at the top (press /) to jump to any block or setting.

    Labels in bold are exactly what you see in WordPress. Paths such as Brigade Blocks → Modules tell you where to click.
