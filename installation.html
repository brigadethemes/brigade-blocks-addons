    Installation & Activation

    Install the plugin in a couple of minutes — from your dashboard, from a ZIP file, or by uploading it to your server.

    Requirements

    Minimum requirements
    RequirementMinimum
    WordPress6.5 or newer (tested up to 7.1)
    PHP7.4 or newer
    EditorThe Block Editor (Gutenberg). The Classic Editor plugin disables blocks.
    User roleAdministrator (the manage_options capability) to install the plugin and change its settings. Anyone who can edit posts can use the blocks.
    Optional pluginsWooCommerce (WooCommerce module); Contact Form 7 or WPForms (Form Styler block).

    Install from your dashboard (recommended)

    1. Open the plugin installer. In your WordPress dashboard go to Plugins → Add New Plugin.
    2. Search. Type Brigade Blocks Addons in the search field.
    3. Install. Click Install Now on the Brigade Blocks Addons card (by Brigade Themes).
    4. Activate. When the button changes, click Activate.
    5. Open the settings. A new Brigade Blocks item appears in the admin menu. You can also click Settings under the plugin name on the Plugins screen.

    Install from a ZIP file

    1. Download the brigade-blocks-addons.zip file (do not unzip it).
    2. Go to Plugins → Add New Plugin and click Upload Plugin at the top.
    3. Click Choose File, select the ZIP file and click Install Now.
    4. Click Activate Plugin.

    Install manually (FTP / file manager)

    1. Unzip the file on your computer. You get a folder named brigade-blocks-addons.
    2. Upload that folder to wp-content/plugins/ on your server.
    3. In the dashboard, go to Plugins and click Activate under Brigade Blocks Addons.

    After activation

    • All available modules and their blocks are switched on by default. The WooCommerce module stays inactive until WooCommerce is installed and active.
    • Open any page in the editor, click + and search for “Brigade” or a block name — Brigade blocks are in the Brigade Blocks category.
    • Optionally switch off what you don’t need on the Brigade Blocks settings screen — disabled modules load nothing at all.

    Updating

    Updates arrive through the normal WordPress update system (Dashboard → Updates, or automatic updates if you enable them on the Plugins screen). Your settings and content are kept. New blocks added in later versions are switched on automatically; blocks you switched off stay off.

    Deactivating and uninstalling

    Deactivating the plugin does not delete your content: the blocks stay saved in your pages, but while the plugin is inactive they are not displayed (blocks that hold other blocks, such as the Container, show only their inner content, without their layout and styling), because Brigade blocks are rendered by the plugin. Reactivate the plugin and they come back exactly as before.

    Deleting the plugin (Plugins → Delete) removes its settings from the database (wpbb_settings and wpbb_version). Your posts and pages are never modified.

    Before removing the plugin for good, replace Brigade blocks on important pages with other blocks — otherwise those parts of your pages will be empty.

    Multisite

    The plugin can be network-activated or activated per site. Each site has its own Brigade Blocks settings.
