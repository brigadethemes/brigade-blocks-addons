    Help

    Support

    Most answers are in this documentation. If you still need help, the support forum is the place to ask.

    Find an answer yourself

    • Use the search at the top of this site (press /).
    • Open the block’s guide — every guide ends with Troubleshooting.
    • Read Troubleshooting and the FAQ.

    Ask in the support forum

    Free support is provided in the Brigade Blocks Addons support forum on WordPress.org. You need a free WordPress.org account to post.

    What to include

    1. What you expected and what happened instead.
    2. Steps to reproduce — which block, which settings, which page.
    3. Versions of WordPress, PHP, the plugin and your theme (Tools → Site Health → Info shows them all).
    4. Other plugins that might be involved (caching, optimisation, security, WooCommerce…).
    5. Screenshots or a link to the page, and any errors from the browser console (F12 → Console).

    Never post passwords, API keys or private customer data in the public forum.

    Reporting a security issue

    Please do not report security problems in the public forum. Contact the author, Brigade Themes, privately through their website, and include the steps to reproduce.

    Feature requests

    Ideas are welcome in the support forum. Planned modules are listed in the Roadmap section of the settings screen.

    Contributing

    Translations can be contributed on translate.wordpress.org. The source code, including the uncompiled scripts in src/, ships with the plugin.
