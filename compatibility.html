    Good to know

    Compatibility

    Brigade Blocks Addons is built on standard WordPress APIs, so it works with block themes, classic themes and the plugins you already use.

    WordPress and PHP

    • WordPress 6.5+ (tested up to 7.1) and PHP 7.4+.
    • Works in the post and page editor, the Site Editor (templates and template parts), widget areas that use blocks, and patterns.
    • Not available with the Classic Editor plugin (it disables blocks).
    • Single sites and multisite networks.

    Themes

    • Block themes (Twenty Twenty-Five and others): fully supported, including templates — e.g. a Mini Cart in the header or an Author Box in the single-post template.
    • Classic themes: supported in posts and pages.
    • Colour and font pickers show your theme’s palette and font sizes first.
    • Choose Inherit from theme in Block typography to use your theme’s fonts.
    • Theme developers can override any design token.

    Plugins

    Plugin integrations
    PluginWhat works
    WooCommerceThe WooCommerce module (6 blocks) appears only while WooCommerce is active. Prices, badges, AJAX add to cart and cart fragments use WooCommerce’s own functions.
    Contact Form 7, WPForms (Lite / Pro)Styled with the Form Styler.
    Security, login-limit, captcha and two-factor pluginsThe Login Form uses WordPress’s standard login functions and hooks, so these keep working; when a plugin needs an extra step, the form falls back to the standard login page.
    Page-cache pluginsSupported. Blocks that show visitor-specific content (Login Form, User Profile, Mini Cart) rely on the cache skipping logged-in users, which caching plugins do by default.
    Custom post types and fieldsPosts and Dynamic Content work with any public post type and with custom fields (post meta), except hidden fields starting with _.
    Any plugin with shortcodesUse the Shortcode block.

    Browsers

    Current versions of Chrome, Edge, Firefox and Safari (desktop and mobile). A few enhancements depend on newer browser features and degrade gracefully: the exclusive “Only one open at a time” accordion and “find in page” for closed tabs and accordions work in current browsers; older browsers simply allow several open items.

    External services

    Some blocks can show content from third-party services. Nothing is sent to these services unless you add the block to a page.

    Third-party services used by blocks
    ServiceBlocksWhen and whatTerms / privacy
    Google MapsGoogle MapsWhen the map loads, the visitor’s browser requests it from Google, which receives the visitor’s IP address, browser details and the address shown. With “Load map on click”, nothing is requested until the visitor clicks.Terms, Maps terms, Privacy
    YouTubeVideo, Video GalleryWithout a custom poster, the thumbnail is loaded from i.ytimg.com; after the visitor presses play, the video is embedded from youtube-nocookie.com. YouTube receives the IP address, browser details and video ID.Terms, Privacy
    VimeoVideo, Video GalleryAfter the visitor presses play, the video is embedded from player.vimeo.com with Do Not Track.Terms, Privacy
    Google Sheets or another CSV linkChart (only with “From a link”)Your server downloads the link you entered and caches it (5 minutes to one day). No visitor data is sent. Private or local network addresses are never contacted.Google Terms, Privacy; for other addresses, the host’s terms apply.

    The Urbanist font is bundled and served from your own site — no request to Google Fonts. Mention the services you use in your site’s privacy policy.
