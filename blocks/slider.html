    Interactive module

    Slider block

    A slider you design yourself: every slide holds any blocks and has its own background image, colour and overlay. Slide or fade, one or several slides at a time.

    Overview

    The Slider shows a row of slides that visitors move through with arrows, dots, swiping or the keyboard. Each slide is a Slide block that can hold any blocks — headings, text, buttons, images, even a Container with columns — and has its own background in the Styles tab. Use it for hero banners, testimonials, feature highlights or announcements.

    For sliders of posts, products, images or videos, use the slider layouts of Posts, Products, Gallery or Video Gallery instead: they fill the slides for you.

    When and why to use it

    • A full-width hero banner with a background photo, headline and button on each slide.
    • Customer testimonials that fade from one quote to the next.
    • Three feature cards at a time on desktop, one at a time on phones.

    Example scenarios

    • Homepage hero: alignment Full width, Effect Slide, Minimum height 560px, arrows and dots On the slides, autoplay every 6 seconds; each slide with a photo background, a dark overlay at 50% and white text.
    • Testimonials: Effect Fade, arrows and dots Below, Name for screen readers “Customer stories”.

    How to add the Slider block

    1. Open the editor. In your WordPress dashboard go to Pages (or Posts) and click the page you want to edit, or click Add New. For headers, footers and templates, use Appearance → Editor (block themes).
    2. Add a new block. Click the blue + (Block Inserter) button in the top-left corner, or the small + that appears where you want the block. You can also type / on an empty line.
    3. Search for the block. Type Slider in the search field. Brigade Blocks appear in the Brigade Blocks category and show the coral block icon.
    4. Insert it. Click Slider in the results. The block appears with three sample slides, each with a heading, a paragraph and a button.
    5. Configure the content. The canvas shows one slide at a time. Use the bar under the slider to move to the previous or next slide, Add slide or Duplicate the current one. Click Edit this slide’s background to select the visible Slide and set its background image, colour or overlay in its Styles tab.
    6. Customise the design. Switch to the Styles tab (half-filled circle icon) to change colours, spacing, borders and more — see Design & styling.
    7. Save or publish. Click Save draft to keep working later, Preview to check it, or Publish / Update to make it live.

    Content settings

    You set up this block in two places: on the block itself in the editor, and in the Settings tab (gear icon) of the sidebar on the right. Every option is listed below, with its default value.

    How to use it
    Click the text in the block on the page and type. Use the block toolbar for bold, italic and links.
    When to use it
    To reach the slide you want to edit.

    Result

    Add slide

    What it does
    Adds a new slide at the end, with a heading, text and a button.
    What to enter or choose
    Click Add slide in the bar.
    How to use it

    Design & styling

    Select the block, open the Styles tab in the settings sidebar (the half-filled circle icon next to the gear) and use the three pickers at the top of the Style panel:

    1. Element — which part of the block to style.
    2. State — Normal, or a state such as Hover (only the states the part supports are offered).
    3. Device — Desktop, Tablet or Mobile, for values that can differ per screen size.

    Responsive settings

    Brigade Blocks uses three screen sizes: Desktop (wider than 1023px), Tablet (600–1023px) and Mobile (599px and narrower). Tablet and Mobile values are optional: when empty, the value of the next larger screen is used.

    Set how many slides show at a time separately for desktop, tablet and mobile. On phones, arrows placed on the slides are hidden (visitors swipe or tap the dots), and the minimum height can be set separately.

    In the Styles tab, pick the Device first; these controls can then have a different value for that screen size: Radius, Margin, Padding, Width, Max width, Height, Min width / Min height / Max height, Block alignment, Position, Top / Right / Bottom / Left, Z-index, Overflow, Opacity (%), Font size, Line height, Letter spacing, Alignment.

    The Visibility panel (Styles tab, Normal state) can hide the block entirely on Desktop, Tablet or Mobile.

    Advanced options

    • HTML anchor (Advanced section of the Settings tab) — a unique name such as pricing, so you can link straight to this block with #pricing at the end of the page address (for example from a menu).
    • Additional CSS class(es) (Advanced section) — for custom CSS from your theme or the Site Editor. Separate several classes with spaces.
    • Custom attributes (Advanced section) — add data-*, title, aria-label, aria-describedby, lang or dir attributes. See Custom attributes.
    • State transition (Styles tab → Effects, Normal state) — how smoothly hover and focus styles animate.
    • Width alignment (block toolbar) — Wide width, Full width, when your theme supports them.

    How it works on your site

    The slides are a native scrolling row with snap points, so they already swipe and scroll without JavaScript. A small shared script (loaded only on pages with a slider or carousel) adds the arrows, dots, autoplay and the fade effect. Without JavaScript, the fade effect shows the first slide.

    Accessibility

    • The slider is a labelled region announced as a carousel; each slide is announced as “2 / 5”.
    • Arrow buttons and dots have labels and work with the keyboard; with the slide row focused, the Left and Right arrow keys move one slide.
    • Autoplay pauses on hover and focus, has a pause button, and never runs for visitors who prefer reduced motion.
    • With the fade effect, hidden slides cannot be reached with the keyboard or a screen reader.

    Tips and best practices

    • Put the most important message on the first slide — many visitors never see the others.
    • Use autoplay sparingly and with a delay of at least 5 seconds.
    • For text over photos, add an overlay in the Slide’s Styles tab so the text stays readable.

    Limitations and notes

    • Up to 4 slides at a time on desktop, 3 on tablet and 2 on mobile.
    • The editor shows one slide at a time.

    Troubleshooting

    The arrows and dots do not appear.

    They only appear when there is something to scroll to: with three slides and three at a time, everything already fits. Also check that Arrows and Dots are on in the Carousel panel.

    Text on my photo is hard to read.

    Select the Slide (Edit this slide’s background), open its Styles tab → Background, and add an overlay colour with some opacity; set the text colour to white.
