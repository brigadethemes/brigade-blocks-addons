    Posts module

    Posts block

    Posts from any public post type in a grid, list, masonry, carousel or slider — with “Load more”, infinite scroll and category filter buttons.

    Overview

    The Posts block lists your blog posts (or pages, portfolio items, products — any public post type) automatically. One block covers every common layout: Grid, List, Masonry, Carousel and a one-at-a-time Slider. Choose which posts appear (a custom query, the most recent, or posts related to the one being read), what each card shows, and optionally let visitors load more posts or filter by category without reloading the page.

    When you change the Layout or Source, the block applies sensible starting values (for example the Slider switches to one column with text over a 16:9 image) — but only for settings you have not changed yourself.

    When and why to use it

    • Blog home and archive-style pages.
    • “Latest news” sections on the homepage.
    • “You may also like” related posts under an article.
    • Portfolio grids with filter buttons.

    Example scenarios

    • Homepage: Most recent, 3 posts, Grid, Card style.
    • Blog page: Custom query, 9 per page, Grid, “Load more” button, Filter bar by Categories.
    • Single post template: Related to the current post, 3 posts, Carousel.
    • Hero: Slider of 5 featured posts (category “Featured”) with text over the image and autoplay.

    How to add the Posts block

    1. Open the editor. In your WordPress dashboard go to Pages (or Posts) and click the page you want to edit, or click Add New. For headers, footers and templates, use Appearance → Editor (block themes).
    2. Add a new block. Click the blue + (Block Inserter) button in the top-left corner, or the small + that appears where you want the block. You can also type / on an empty line.
    3. Search for the block. Type Posts in the search field. Brigade Blocks appear in the Brigade Blocks category and show the coral block icon.
    4. Insert it. Click Posts in the results. The block appears with a live preview of your latest posts.
    5. Configure the content. Edit the text directly on the block, then open the Settings tab (gear icon) in the right-hand sidebar for the options described below. If the sidebar is hidden, click the gear icon in the top-right corner.
    6. Customise the design. Switch to the Styles tab (half-filled circle icon) to change colours, spacing, borders and more — see Design & styling.
    7. Save or publish. Click Save draft to keep working later, Preview to check it, or Publish / Update to make it live.

    Settings panel: Query

    Which posts are shown.

    Source

    What it does
    How posts are chosen.
    What to enter or choose
    One of: Custom query, Most recent, Related to the current post.
    Default
    Custom query
    How to use it
    Open the dropdown and pick an option.
    When to use it
    Custom query: pick the post type, terms, order and more. Most recent: the newest posts, nothing else to set (starts as a compact list of 5). Related: posts sharing a category or tag with the post being viewed.
    Example
    Related under each blog post.
    Result
    The preview updates.
    Good to know
    Related only works where there is a current post — a single-post template or inside a post. The current post is always left out of related posts.

    1. Element — which part of the block to style.
    2. State — Normal, or a state such as Hover (only the states the part supports are offered).
    3. Device — Desktop, Tablet or Mobile, for values that can differ per screen size.

    Responsive settings

    Brigade Blocks uses three screen sizes: Desktop (wider than 1023px), Tablet (600–1023px) and Mobile (599px and narrower). Tablet and Mobile values are optional: when empty, the value of the next larger screen is used.

    Set Columns separately for desktop, tablet and mobile in the Layout panel. Carousels show that many cards per view on each device.

    In the Styles tab, pick the Device first; these controls can then have a different value for that screen size: Radius, Margin, Padding, Width, Max width, Height, Min width / Min height / Max height, Opacity (%), Block alignment, Position, Top / Right / Bottom / Left, Z-index, Overflow, Font size, Line height, Letter spacing, Alignment.

    The Visibility panel (Styles tab, Normal state) can hide the block entirely on Desktop, Tablet or Mobile.

    Advanced options

    • HTML anchor (Advanced section of the Settings tab) — a unique name such as pricing, so you can link straight to this block with #pricing at the end of the page address (for example from a menu).
    • Additional CSS class(es) (Advanced section) — for custom CSS from your theme or the Site Editor. Separate several classes with spaces.
    • Custom attributes (Advanced section) — add data-*, title, aria-label, aria-describedby, lang or dir attributes. See Custom attributes.
    • State transition (Styles tab → Effects, Normal state) — how smoothly hover and focus styles animate.
    • Width alignment (block toolbar) — Wide width, Full width, when your theme supports them.

    How it works on your site

    Posts are rendered on the server (fast and SEO-friendly). Scripts are loaded only when needed: the carousel script for Carousel/Slider, and a small AJAX script for Load more, Infinite scroll and the Filter bar. Only published, non-password-protected posts of public post types are ever listed.

    Accessibility

    • Newly loaded posts are announced to screen readers.
    • Filter buttons announce which one is pressed.
    • Carousels: arrows and dots are keyboard-accessible buttons; autoplay pauses on hover and focus, has a pause button, and never runs for visitors who prefer reduced motion.
    • Give posts featured images with alternative text in the Media Library.

    Tips and best practices

    • Use the same Image aspect ratio for all cards to keep rows tidy.
    • For a “featured + latest” layout: a Slider of 1–5 posts, and below it a Grid with Skip first = the number of slides.

    Limitations and notes

    • Up to 24 posts per page.
    • Carousel and Slider layouts cannot use Load more or the Filter bar.
    • Related posts need a current post (templates or inside a post).

    Troubleshooting

    The block shows nothing on the site.

    No posts match the settings. Check the post type and term filters, and that the posts are published (not drafts, private or password-protected).

    Related posts are empty.

    The post being viewed needs at least one category or tag shared with other published posts.

    “Load more” does not appear.

    The button only appears when there are more posts than the Number of posts.
