    Utilities module

    WhatsApp Chat block

    Lets visitors message you on WhatsApp: a floating chat button with an optional greeting card, or a button in your content.

    Overview

    WhatsApp Chat adds a WhatsApp button. Floating keeps a round button in the bottom corner of the page; it can first open a small card with your name, a status line and a greeting, whose Start chat button opens WhatsApp. In content places a green button where the block is. Nothing is loaded from WhatsApp until a visitor clicks, so it has no effect on speed or privacy.

    To show the floating button on every page, add the block to a template part such as the footer (Appearance → Editor).

    At a glance

    Block name
    wpbb/whatsapp-chat
    Module
    Utilities
    Find it by searching
    WhatsApp Chat
    Loads JavaScript on the site
    Yes, a small script, only on pages that use this block

    When and why to use it

    • Quick customer support for shops and local businesses.
    • A “Message us” call to action on contact and pricing pages.

    Example scenarios

    • Shop: in the footer template, Floating, bottom right, greeting card “Sam from Support — Typically replies within an hour”.
    • Contact page: In content, button text “Message us on WhatsApp”, pre-filled message “Hi, I have a question about…”.

    How to add the WhatsApp Chat block

    1. Open the editor. In your WordPress dashboard go to Pages (or Posts) and click the page you want to edit, or click Add New. For headers, footers and templates, use Appearance → Editor (block themes).
    2. Add a new block. Click the blue + (Block Inserter) button in the top-left corner, or the small + that appears where you want the block. You can also type / on an empty line.
    3. Search for the block. Type WhatsApp Chat in the search field. Brigade Blocks appear in the Brigade Blocks category and show the coral block icon.
    4. Insert it. Click WhatsApp Chat in the results. The block appears with a preview of the button, and a reminder to add your number.
    5. Configure the content. Edit the text directly on the block, then open the Settings tab (gear icon) in the right-hand sidebar for the options described below. If the sidebar is hidden, click the gear icon in the top-right corner.
    6. Customise the design. Switch to the Styles tab (half-filled circle icon) to change colours, spacing, borders and more — see Design & styling.
    7. Save or publish. Click Save draft to keep working later, Preview to check it, or Publish / Update to make it live.

    Content settings

    You set up this block in two places: on the block itself in the editor, and in the Settings tab (gear icon) of the sidebar on the right. Every option is listed below, with its default value.

    Settings panel: WhatsApp

    WhatsApp number

    What it does
    The number chats go to.
    What to enter or choose
    Full international number with country code; spaces, dashes and + are fine.
    Default
    Empty
    How to use it
    Type into the text field. Changes appear in the preview right away.
    When to use it
    Required — nothing is shown on the site without a valid number.
    Example
    +44 7700 900123.
    Result
    Links to https://wa.me/447700900123.

    Pre-filled message

    What it does
    Text typed into the chat for the visitor.
    What to enter or choose
    Optional text.
    Default
    Empty
    How to use it
    Type into the box. Line breaks are kept where the block allows them.
    When to use it
    To give context, e.g. which page they came from.
    Example
    “Hi! I have a question about my order.”
    Result
    The visitor can edit it before sending.

    Design & styling

    Select the block, open the Styles tab in the settings sidebar (the half-filled circle icon next to the gear) and use the three pickers at the top of the Style panel:

    1. Element — which part of the block to style.
    2. State — Normal, or a state such as Hover (only the states the part supports are offered).
    3. Device — Desktop, Tablet or Mobile, for values that can differ per screen size.

    Only panels that make sense for the chosen part and state are shown. The full meaning of every control is in the Styling Controls guide; below is exactly what WhatsApp Chat offers.

    Responsive settings

    Brigade Blocks uses three screen sizes: Desktop (wider than 1023px), Tablet (600–1023px) and Mobile (599px and narrower). Tablet and Mobile values are optional: when empty, the value of the next larger screen is used.

    In the Styles tab, pick the Device first; these controls can then have a different value for that screen size: Font size, Line height, Letter spacing, Alignment, Radius, Padding, Width, Max width, Height, Min width / Min height / Max height, Opacity (%), Margin, Block alignment, Position, Top / Right / Bottom / Left, Z-index, Overflow.

    The Visibility panel (Styles tab, Normal state) can hide the block entirely on Desktop, Tablet or Mobile.

    Advanced options

    • HTML anchor (Advanced section of the Settings tab) — a unique name such as pricing, so you can link straight to this block with #pricing at the end of the page address (for example from a menu).
    • Additional CSS class(es) (Advanced section) — for custom CSS from your theme or the Site Editor. Separate several classes with spaces.
    • Custom attributes (Advanced section) — add data-*, title, aria-label, aria-describedby, lang or dir attributes. See Custom attributes.
    • State transition (Styles tab → Effects, Normal state) — how smoothly hover and focus styles animate.

    How it works on your site

    A link to https://wa.me/<number> that opens in a new tab. The greeting card is a native <details> element, so it works without JavaScript; a tiny script adds Escape and click-outside to close it. No WhatsApp scripts, cookies or requests until a visitor clicks.

    Limitations and notes

    • Opens WhatsApp (app or WhatsApp Web); it is not a live chat inside your site.
    • One number per block.

    Troubleshooting

    The button is not on the site.

    The number is missing or too short. Enter the full number with country code. Also check Show on.

    The floating button covers my cookie banner or another chat.

    Move it with Corner, or adjust its position in the Styles tab.
