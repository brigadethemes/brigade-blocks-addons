    Posts module

    Dynamic Content block

    Shows one field of the current post — title, excerpt, dates, author, terms, comments, reading time or a custom field. Built for templates and the Query Loop.

    Overview

    Dynamic Content outputs a single piece of information about the current post, with optional icon, prefix and suffix. It is made for templates (Appearance → Editor) and the WordPress Query Loop, where each item shows its own values.

    At a glance

    Block name
    wpbb/dynamic-content
    Module
    Posts
    Find it by searching
    Dynamic Content
    Loads JavaScript on the site
    No

    When and why to use it

    • Post meta lines in templates (“Updated on…”, “5 min read”).
    • Custom field values such as a price, location or event date.
    • Post cards built with the WordPress Query Loop.

    Example scenarios

    • Single post template: Last modified date with prefix “Updated”, date format “F j, Y”, calendar icon.
    • Query Loop card: Custom field price with prefix “$”.

    How to add the Dynamic Content block

    1. Open the editor. In your WordPress dashboard go to Pages (or Posts) and click the page you want to edit, or click Add New. For headers, footers and templates, use Appearance → Editor (block themes).
    2. Add a new block. Click the blue + (Block Inserter) button in the top-left corner, or the small + that appears where you want the block. You can also type / on an empty line.
    3. Search for the block. Type Dynamic Content in the search field. Brigade Blocks appear in the Brigade Blocks category and show the coral block icon.
    4. Insert it. Click Dynamic Content in the results. The block appears with a preview of the current post’s title.
    5. Configure the content. Edit the text directly on the block, then open the Settings tab (gear icon) in the right-hand sidebar for the options described below. If the sidebar is hidden, click the gear icon in the top-right corner.
    6. Customise the design. Switch to the Styles tab (half-filled circle icon) to change colours, spacing, borders and more — see Design & styling.
    7. Save or publish. Click Save draft to keep working later, Preview to check it, or Publish / Update to make it live.

    Content settings

    You set up this block in two places: on the block itself in the editor, and in the Settings tab (gear icon) of the sidebar on the right. Every option is listed below, with its default value.

    Block toolbar

    Align

    What it does
    Aligns the value.
    What to enter or choose
    One of: Align text left, Align text center, Align text right.
    Default
    Align text left
    How to use it
    Select the block; the button is in the toolbar that appears above it.
    Example
    Centre.
    Result
    The text moves.

    Settings panel: Field

    Show

    What it does
    Which field is shown.
    What to enter or choose
    One of: Title, Excerpt, Publish date, Last modified date, Author name, Terms (categories, tags…), Comment count, Reading time, Custom field (post meta).
    Default
    Title
    How to use it
    Open the dropdown and pick an option.
    When to use it
    Always.
    Example
    Reading time.
    Result
    The value of the current post. Reading time assumes 220 words per minute.

    TaxonomyShown when Show is Terms

    What it does
    Which terms to list.
    What to enter or choose
    A public taxonomy of the post type.
    Default
    category
    How to use it
    Open the dropdown and pick an option.
    When to use it
    With Terms.
    Example
    Tags.
    Result
    Terms separated by commas, each linking to its archive.

    Meta keyShown when Show is Custom field

    What it does
    Which custom field to read.
    What to enter or choose
    The custom field name.
    Default
    Empty
    How to use it
    Type into the text field. Changes appear in the preview right away.
    When to use it
    With Custom field.
    Example
    price.
    Result
    The field’s value as text.
    Good to know
    Protected keys (starting with _) are never shown.

    Date formatShown when Show is a date

    What it does
    How the date is written.
    What to enter or choose
    A PHP date format, or empty for the site default.
    Default
    Empty
    How to use it
    Type into the text field. Changes appear in the preview right away.
    When to use it
    To differ from Settings → General.
    Example
    F j, Y → “March 5, 2026”.
    Result
    The date uses your format.

    HTML tag

    What it does
    The element wrapping the value.
    What to enter or choose
    One of: P, SPAN, DIV, H1, H2, H3, H4, H5, H6.
    Default
    P
    How to use it
    Open the dropdown and pick an option.
    When to use it
    Headings for titles; P or SPAN otherwise.
    Example
    H1 for the title in a single template.
    Result
    Structure only.

    Link to the postShown when Show is not Terms

    What it does
    Makes the value link to the post.
    What to enter or choose
    On or off.
    Default
    Off
    How to use it
    Click the switch to turn it on (blue) or off.
    When to use it
    In lists of posts.
    Example
    On for titles in a loop.
    Result
    The value becomes a link.

    Settings panel: Before & after

    Icon

    What it does
    An icon before the value.
    What to enter or choose
    An icon, or None.
    Default
    Empty
    How to use it
    Click the icon button to open the icon library, search by name (for example “arrow” or “phone”) and click an icon. “None” removes it.
    When to use it
    Optional.
    Example
    “clock” for reading time.
    Result
    An 18px icon.

    Prefix

    What it does
    Text before the value.
    What to enter or choose
    Any short text. A space is added between it and the value automatically.
    Default
    Empty
    How to use it
    Type into the text field. Changes appear in the preview right away.
    When to use it
    Optional.
    Example
    “Updated”.
    Result
    Shown before the value, e.g. “Updated September 30, 2026”.

    Suffix

    What it does
    Text after the value.
    What to enter or choose
    Any short text. A space is added between the value and it automatically.
    Default
    Empty
    How to use it
    Type into the text field. Changes appear in the preview right away.
    When to use it
    Optional. Note that Comment count and Reading time already include their unit (“3 comments”, “4 min read”).
    Example
    “ago” after a date, or “/ 5” after a rating custom field.
    Result
    Shown after the value.

    Fallback text

    What it does
    Shown when the field is empty.
    What to enter or choose
    Text, or empty to hide the block.
    Default
    Empty
    How to use it
    Type into the text field. Changes appear in the preview right away.
    When to use it
    When a field may be empty.
    Example
    “No comments yet”.
    Result
    Empty fields show this text instead of nothing.

    Design & styling

    Select the block, open the Styles tab in the settings sidebar (the half-filled circle icon next to the gear) and use the three pickers at the top of the Style panel:

    1. Element — which part of the block to style.
    2. State — Normal, or a state such as Hover (only the states the part supports are offered).
    3. Device — Desktop, Tablet or Mobile, for values that can differ per screen size.

    Responsive settings

    Brigade Blocks uses three screen sizes: Desktop (wider than 1023px), Tablet (600–1023px) and Mobile (599px and narrower). Tablet and Mobile values are optional: when empty, the value of the next larger screen is used.

    In the Styles tab, pick the Device first; these controls can then have a different value for that screen size: Font size, Line height, Letter spacing, Alignment, Radius, Margin, Padding, Width, Max width, Height, Min width / Min height / Max height, Block alignment, Position, Top / Right / Bottom / Left, Z-index, Overflow, Opacity (%).

    The Visibility panel (Styles tab, Normal state) can hide the block entirely on Desktop, Tablet or Mobile.

    Advanced options

    • HTML anchor (Advanced section of the Settings tab) — a unique name such as pricing, so you can link straight to this block with #pricing at the end of the page address (for example from a menu).
    • Additional CSS class(es) (Advanced section) — for custom CSS from your theme or the Site Editor. Separate several classes with spaces.
    • Custom attributes (Advanced section) — add data-*, title, aria-label, aria-describedby, lang or dir attributes. See Custom attributes.
    • State transition (Styles tab → Effects, Normal state) — how smoothly hover and focus styles animate.

    How it works on your site

    Plain server-rendered text. Password-protected or private posts do not reveal their values.

    Limitations and notes

    • One field per block.
    • Custom field values are shown as plain text.

    Troubleshooting

    Nothing is shown.

    The field is empty for that post (for example no custom field value). Add Fallback text to show something instead.
