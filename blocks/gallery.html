    Media module

    Gallery block

    Images in a grid, masonry, carousel or slider — with a lightbox, captions, hover effects and a filter bar built from image tags.

    Overview

    The Gallery shows a set of images in four layouts: Grid (equal tiles), Masonry (natural heights, Pinterest-style), Carousel (several per view, swipeable) and Slider (one large image at a time). Clicking an image can open an accessible lightbox with previous/next navigation. You can tag images (“Kitchen”, “Bathroom”) and show filter buttons so visitors can narrow the gallery down.

    At a glance

    Block name
    wpbb/gallery
    Module
    Media
    Find it by searching
    Gallery
    Loads JavaScript on the site
    Only for the lightbox, filter buttons or Carousel/Slider layouts

    When and why to use it

    • Portfolios and project photos.
    • Product or venue galleries with a lightbox.
    • Filterable galleries by category.

    Example scenarios

    • Interior designer: Masonry, Lightbox, filter buttons for “Kitchen”, “Living room”, “Bathroom”.
    • Hotel: Slider of 8 photos with captions over the image and autoplay.

    See it in action

    These are live examples: real Gallery blocks rendered by WordPress with the plugin’s own styles and scripts. Use the buttons to see how they adapt to tablet and phone screens.

    How to add the Gallery block

    1. Open the editor. In your WordPress dashboard go to Pages (or Posts) and click the page you want to edit, or click Add New. For headers, footers and templates, use Appearance → Editor (block themes).
    2. Add a new block. Click the blue + (Block Inserter) button in the top-left corner, or the small + that appears where you want the block. You can also type / on an empty line.
    3. Search for the block. Type Gallery in the search field. Brigade Blocks appear in the Brigade Blocks category and show the coral block icon.
    4. Insert it. Click Gallery in the results. The block appears with a placeholder to upload images or pick them from the Media Library.
    5. Configure the content. Upload images or click Media Library and select several. Click an image in the block to edit its alt text, caption and filter tags in the Selected image panel. Use Edit gallery in the toolbar to add, remove or reorder images.
    6. Customise the design. Switch to the Styles tab (half-filled circle icon) to change colours, spacing, borders and more — see Design & styling.
    7. Save or publish. Click Save draft to keep working later, Preview to check it, or Publish / Update to make it live.

    Content settings

    You set up this block in two places: on the block itself in the editor, and in the Settings tab (gear icon) of the sidebar on the right. Every option is listed below, with its default value.

    On the block (in the editor canvas)

    Images

    What it does
    The pictures in the gallery.
    What to enter or choose
    Several images from the Media Library or new uploads.
    Default
    None selected
    How to use it
    Use the placeholder at first, then Edit gallery in the toolbar.
    When to use it
    Always — an empty gallery is not shown.
    Example
    12 project photos.
    Result
    The images appear in the chosen layout.

    Selecting an image

    What it does
    Clicking an image in the block selects it and opens the Selected image panel in the sidebar.
    What to enter or choose
    Click any image (or its “Edit image N” button).
    How to use it
    Click the text in the block on the page and type. Use the block toolbar for bold, italic and links.
    When to use it
    To edit one image’s details.
    Example
    —
    Result
    The panel shows that image’s settings.

    Block toolbar

    Edit gallery

    What it does
    Opens the Media Library to add, remove or reorder images.
    What to enter or choose
    Click the button.
    How to use it

    Example
    Add three new photos.
    Result
    The gallery updates; alt text, captions and tags you already set are kept.

    1. Element — which part of the block to style.

    Responsive settings

    Brigade Blocks uses three screen sizes: Desktop (wider than 1023px), Tablet (600–1023px) and Mobile (599px and narrower). Tablet and Mobile values are optional: when empty, the value of the next larger screen is used.

    In the Styles tab, pick the Device first; these controls can then have a different value for that screen size: Radius, Opacity (%), Margin, Padding, Width, Max width, Height, Min width / Min height / Max height, Block alignment, Position, Top / Right / Bottom / Left, Z-index, Overflow, Font size, Line height, Letter spacing, Alignment.

    The Visibility panel (Styles tab, Normal state) can hide the block entirely on Desktop, Tablet or Mobile.

    Advanced options

    • HTML anchor (Advanced section of the Settings tab) — a unique name such as pricing, so you can link straight to this block with #pricing at the end of the page address (for example from a menu).
    • Additional CSS class(es) (Advanced section) — for custom CSS from your theme or the Site Editor. Separate several classes with spaces.
    • Custom attributes (Advanced section) — add data-*, title, aria-label, aria-describedby, lang or dir attributes. See Custom attributes.
    • State transition (Styles tab → Effects, Normal state) — how smoothly hover and focus styles animate.
    • Width alignment (block toolbar) — Wide width, Full width, when your theme supports them.

    How it works on your site

    Images are regular responsive images with srcset. Each image is a normal link to the full-size file, so it works without JavaScript; with JavaScript the lightbox opens instead. The lightbox and carousel scripts load only when used.

    Accessibility

    • Lightbox: a native dialog — focus stays inside, Esc closes it and returns focus to the image; arrow keys and swipe move between images.
    • Images without alternative text are treated as decorative.
    • Filter buttons announce which one is pressed.
    • Filtered-out images are skipped in the lightbox.

    Tips and best practices

    • Upload images of similar size and orientation for tidy grids — or use Masonry.
    • Keep tags short and few (3–6) so the filter bar stays readable.

    Limitations and notes

    • Carousel and Slider layouts have no filter bar.
    • Images must come from the Media Library.
