    Forms module

    User Profile block

    The logged-in visitor’s avatar, name and bio with account and log-out links — or a login link for logged-out visitors.

    Overview

    User Profile greets the visitor who is logged in: their avatar, name, optional email and bio, plus links to their account and to log out. Visitors who are not logged in can see a login link instead (or nothing).

    At a glance

    Block name
    wpbb/user-profile
    Module
    Forms
    Find it by searching
    User Profile
    Loads JavaScript on the site
    No

    When and why to use it

    • Member dashboards.
    • Header or sidebar account boxes.

    Example scenarios

    • Members page: Vertical layout, greeting “Welcome back”, account and log-out links; logged-out visitors get “Log in” linking to your login page.

    How to add the User Profile block

    1. Open the editor. In your WordPress dashboard go to Pages (or Posts) and click the page you want to edit, or click Add New. For headers, footers and templates, use Appearance → Editor (block themes).
    2. Add a new block. Click the blue + (Block Inserter) button in the top-left corner, or the small + that appears where you want the block. You can also type / on an empty line.
    3. Search for the block. Type User Profile in the search field. Brigade Blocks appear in the Brigade Blocks category and show the coral block icon.
    4. Insert it. Click User Profile in the results. The block appears with a preview using your own account.
    5. Configure the content. Edit the text directly on the block, then open the Settings tab (gear icon) in the right-hand sidebar for the options described below. If the sidebar is hidden, click the gear icon in the top-right corner.
    6. Customise the design. Switch to the Styles tab (half-filled circle icon) to change colours, spacing, borders and more — see Design & styling.
    7. Save or publish. Click Save draft to keep working later, Preview to check it, or Publish / Update to make it live.

    Content settings

    You set up this block in two places: on the block itself in the editor, and in the Settings tab (gear icon) of the sidebar on the right. Every option is listed below, with its default value.

    Settings panel: Profile

    Layout

    What it does
    Avatar beside or above the text.
    What to enter or choose
    One of: Horizontal, Vertical (centered).
    Default
    Horizontal
    How to use it
    Click one of the buttons in the group.
    When to use it
    Always optional.
    Example
    Vertical in a sidebar.
    Result
    The layout changes.

    Login page URLShown when Show is A login link

    Where the login link goes.
    What to enter or choose

    Design & styling

    Select the block, open the Styles tab in the settings sidebar (the half-filled circle icon next to the gear) and use the three pickers at the top of the Style panel:

    1. Element — which part of the block to style.
    2. State — Normal, or a state such as Hover (only the states the part supports are offered).
    3. Device — Desktop, Tablet or Mobile, for values that can differ per screen size.

    States for this part:

    • Hover — When the mouse pointer is over it. (Touch screens have no hover; they show the normal style.)
    • Focus — When it has keyboard focus — reached with the Tab key. Mouse clicks usually do not show focus styles.

    Responsive settings

    Brigade Blocks uses three screen sizes: Desktop (wider than 1023px), Tablet (600–1023px) and Mobile (599px and narrower). Tablet and Mobile values are optional: when empty, the value of the next larger screen is used.

    In the Styles tab, pick the Device first; these controls can then have a different value for that screen size: Font size, Line height, Letter spacing, Alignment, Radius, Padding, Width, Max width, Height, Min width / Min height / Max height, Opacity (%).

    Advanced options

    • HTML anchor (Advanced section of the Settings tab) — a unique name such as pricing, so you can link straight to this block with #pricing at the end of the page address (for example from a menu).
    • Additional CSS class(es) (Advanced section) — for custom CSS from your theme or the Site Editor. Separate several classes with spaces.

    How it works on your site

    Rendered on the server for the current visitor. No JavaScript.

    Limitations and notes

    • This block shows different content to each visitor. If you use a page-cache plugin, exclude pages with this block from the cache for logged-in users (most caching plugins do this automatically).
