    Help

    Frequently Asked Questions

    Quick answers to the questions people ask most. For step-by-step fixes, see Troubleshooting.

    Questions and answers

    Is Brigade Blocks Addons free?

    Yes. The plugin is free and open source (GPLv2 or later), available from the WordPress.org plugin directory.

    Do I need a page builder?

    No. It is built entirely on the native WordPress Block Editor (Gutenberg). There is nothing extra to learn beyond the editor you already use.

    Does it work with my theme?

    Yes — block themes and classic themes. Colour and font pickers show your theme’s palette, and you can make the blocks use your theme’s fonts with “Inherit from theme”. See Compatibility.

    What happens to my content if I disable a module or block?

    Nothing is deleted. The blocks stop being displayed and come back exactly as they were when you switch the module or block on again.

    What happens if I deactivate the plugin?

    Your content stays saved in your pages, but Brigade blocks are not displayed while the plugin is inactive. Reactivate it and they return. See Deactivating and uninstalling.

    Will the plugin slow down my site?

    It is designed not to: styles and scripts load only on pages that use a block, disabled modules load nothing, many blocks use no JavaScript and videos and maps can wait for a click. See Performance.

    Can I change the colours and fonts of all blocks at once?

    Yes. Override the design tokens (CSS custom properties) in your theme, for example :root { --wpbb-brand: #0a7cff; }, and choose the block typography in the settings. See Design tokens.

    Can I style hover effects and mobile layouts without code?

    Yes. The Styles tab has an Element, a State (Normal, Hover, Focus, Active) and a Device (Desktop, Tablet, Mobile) picker. See Styling Controls and Responsive Design.

    Does it work with WooCommerce?

    Yes. The WooCommerce module adds Products, Product Categories, Product Search, Add to Cart, Mini Cart and Store Page blocks while WooCommerce is active.

    Which form plugins are supported?

    The Form Styler styles Contact Form 7 and WPForms forms. The Login Form block provides its own log-in, registration and lost-password forms.

    Is it GDPR-friendly?

    The plugin itself stores no visitor data and serves its font from your own site. YouTube, Vimeo and Google Maps content can be set to load only after a click. Read External services and mention the services you use in your privacy policy.

    Is it accessible?

    Yes — keyboard support, screen-reader labels, visible focus and reduced-motion support are built in. See Accessibility for the details and a checklist.

    Can I use the blocks in templates and headers?

    Yes. With a block theme, open Appearance → Editor to use blocks in templates and template parts — for example a Mini Cart in the header or an Author Box in the single-post template.

    How do I show post data inside text?

    Use the Dynamic Content block for a single styled value. Live values inside running text (Dynamic Tags) are part of Brigade Blocks Addons Pro.

    Can developers extend the plugin?

    Yes. There are filters and actions for modules, blocks, icons, queries, breakpoints and more. See Developer hooks.

    Where is the source code of the compiled scripts?

    The human-readable source is included in the plugin’s src/ folder. Build it with Node.js: npm install then npm run build.

    Is the plugin translation-ready?

    Yes. All texts use the brigade-blocks-addons text domain and can be translated on translate.wordpress.org or with a translation plugin.

    Didn’t find your question? Check Troubleshooting or get support.
