    Help

    Troubleshooting

    Most problems have a simple cause. Find your symptom below; each block guide also has its own Troubleshooting section.

    First steps for any problem

    1. Clear caches — your caching plugin, your host’s cache and your browser (or test in a private window).
    2. Update WordPress, your theme and your plugins.
    3. Check the settings — is the module and block switched on?
    4. Look for conflicts — temporarily switch to a default theme (e.g. Twenty Twenty-Five) and deactivate other plugins one by one on a staging site.
    5. Check the browser console (F12 → Console) for JavaScript errors.

    Installation & setup

    I can’t find Brigade blocks in the inserter.

    Check that the plugin is active (Plugins), then that the module and the block are switched on in Brigade Blocks. Search by the block name, or look in the Brigade Blocks category. Inner blocks (Accordion Item, Tab…) only appear while their parent is selected.

    The WooCommerce blocks are missing.

    The WooCommerce module only works while WooCommerce is installed and active. Activate WooCommerce, then check the module switch.

    The settings screen is not in my menu.

    Only administrators (users with the manage_options capability) see the Brigade Blocks menu.

    Blocks on the site

    A block appears in the editor but not on the published page.

    Most blocks are hidden when they have no content (empty text, no image, no address, no matching posts). Check the block’s content, then the Visibility panel in the Styles tab (it may be hidden on that device). The block’s guide lists the exact conditions under Troubleshooting.

    My blocks disappeared after switching off a module.

    That is expected: disabled blocks are not displayed. Nothing is deleted — switch the module or block on again and they return.

    My style changes don’t show on the site.

    Save/update the page, then clear any page cache (caching plugin, host or CDN) and reload. Also check that you edited the right Element, State (Normal vs Hover) and Device in the Styles tab — a value set on Mobile only applies to phones.

    The fonts look different from the documentation screenshots.

    Check Block typography: “Inherit from theme” uses your theme’s fonts. A Font family set in the Styles tab also overrides it.

    Styles from my theme override the blocks.

    Block styles set in the Styles tab are scoped and strong enough to beat block defaults. If your theme uses very specific rules, set the value in the Styles tab rather than relying on defaults, or ask your theme developer to use the design tokens.

    Interactive blocks and scripts

    Tabs, carousels or counters don’t work.

    These use small scripts. Check your browser console for errors from other plugins, and make sure optimisation plugins don’t delay or combine scripts in a way that breaks them — exclude the brigade-blocks-addons scripts from “delay JavaScript” features.

    The video or map doesn’t load.

    With click-to-load on, it loads only after pressing play / “Show map”. Private YouTube videos can’t be embedded. Content-blocking browser extensions may block YouTube, Vimeo or Google Maps.

    The Login Form redirects to wp-login.php.

    A security or two-factor plugin needed an extra step, so the form fell back to the standard login page. That is intentional.

    Posts “Load more” or filters don’t work.

    They use the WordPress REST API. Security plugins that block the REST API for visitors will break them — allow the wpbb/v1 routes.

    Data and dynamic content

    My Google Sheet chart shows old or sample data.

    Share the sheet with “Anyone with the link” (or publish it to the web). The chart re-checks after the “Check for new data” interval; until the link can be read it shows the saved data.

    A Dynamic Content block is empty.

    The field is empty for that post, or it is a hidden custom field (starting with _), which is never shown. Add Fallback text to show something instead.

    In the editor

    I can’t select the Container behind other blocks.

    Select a block inside it, then use the “Select parent” arrow in the toolbar, or open the List View.

    The Styles tab shows fewer panels than described.

    Panels depend on the selected Element and State: for example background images, radius and visibility exist only in the Normal state, and the Focus indicator only in the Focus state.

    The editor shows “This block contains unexpected or invalid content”.

    This can happen after copying block HTML between sites. Click Attempt recovery. Brigade blocks are rendered on the server, so their saved markup is minimal and recovery usually succeeds.

    Still stuck?

    See Support for how to get help and what information to include.
