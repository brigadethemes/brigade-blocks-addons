# Brigade Blocks Addons — Documentation

User documentation for [Brigade Blocks Addons](https://wordpress.org/plugins/brigade-blocks-addons/), the free block library for the WordPress Block Editor by Brigade Themes.

Read it online: https://brigadethemes.github.io/brigade-blocks-addons/

This is a static site: open `index.html` in a browser, or publish it with GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
